# ![FinTrack](/image/favicon.svg) FinTrack

![FinTrack](/image/Fintrack.png)

Personal finance tracker built with HTML, Tailwind CSS, and vanilla JavaScript.

### Features

* Add, edit, and delete transactions
* Income & expense tracking
* Dashboard with chart
* Search & filter
* Light / dark mode
* `localStorage`

### Tech Stack

HTML · Tailwind CSS · JavaScript · Chart.js · Lucide Icons

Made for learning.
